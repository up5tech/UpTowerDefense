### Environment finding (important, recurring)

`flutter test` fails in the sandboxed IDE shell with
`Unable to connect to flutter_tester process: WebSocketException: Invalid
WebSocket upgrade request`. The cause is **not** the code: `HTTP_PROXY` /
`HTTPS_PROXY` are set in the shell and intercept `flutter_tester`'s local
WebSocket. The working invocation is:

```bash
env -u HTTP_PROXY -u HTTPS_PROXY -u http_proxy -u https_proxy flutter test
```

`flutter analyze` and `dart format` are unaffected by the proxy.
